# Bachelor Kitchen

Bachelor Kitchen is a full-stack subscription meal planning platform designed for busy professionals, students, and fitness-focused individuals who want affordable, easy-to-prepare nutritious meals.

## Features

- Monthly meal timetable
- Recipe browsing and filtering
- Subscriber-only nutrition, video, and chef details
- Delivery fee calculator
- Subscription and billing flows
- Admin dashboard for meals, timetable, and content management
- REST APIs with auth and subscription enforcement

## Stack

- Frontend: React + Vite + JavaScript + React Router + Axios
- Backend: Node.js + Express + MongoDB + Mongoose
- Auth: JWT and bcrypt
